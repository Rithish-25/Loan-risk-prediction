loan risk prediction

local server = http://127.0.0.1:3000/
live cloud server = https://loan-risk-prediction-z9jk.onrender.com

backend (cd to backend directory)
python -m uvicorn main:app --port 8000 --reload

sync live cloud database to local loans.db (cd to backend directory)
python live.py

frontend (cd to frontend directory)
npm install
npm run dev

view 5-model accuracy output in terminal (open a terminal in project root directory):
python notebook/evaluate_models.py

(or if you are inside notebook directory):
cd notebook
python evaluate_models.py

other model commands (run from project root directory):
python notebook/train_all_models.py     # Retrain all 5 ML models (RF, XGB, LGBM, LogReg, GBM)
python notebook/compare_models.py       # Compare predictions for a sample applicant across all 5 models
